MA Plot and Shrinkage

The plotMA() function of DESeq2 draws a scatterplot of the mean normalized counts against the log2FoldChange values. It helps to see the significant genes in the context of the entire dataset, and notably also to pinpoint unusual features of the entire count distribution.

plotMA(res_genotype)

Observe:

  • the number of significant genes is REALLY small compared to the entire distribution
  • there is a slight bimodality in the point cloud – this is unusual

MA Plot and Shrinkage

The lfcShrink() function of DESeq2

  • is an alternative to results()
  • shifts noisy, unreliable log2FoldChange values towards zero
  • see ?lfcShrink and the DESeq2 vignette for available shrinkage methods
res_genotype_shrunken <-
  lfcShrink(dds_genotype, 
            ## MIND: "coef", 
            ##       not "name" as in results() !
            coef="genotype_nmrhas2_vs_creer", 
            type="ashr")

plotMA(res_genotype_shrunken)

The bimodality is much more clear after shrinkage – this is really unusual

Why So Few Significant Genes?

Why So Few Significant Genes?

I had on purpose omitted a step which should really be done in the beginning: Get to know the sources of variability in your count matrix!  

All known such sources should be either eliminated or stated in the design given to DESeq2. Otherwise the neglected factors will be treated as random variance by the model and this may mask a real effect.

Why So Few Significant Genes?

Principal Component Analysis (PCA) projects the transcriptome of each sample onto a point on a two-dimensional canvas, such that the among-sample variance is maximal.

It helps to answer questions like:

  • Do the samples cluster as your hypotheses suggest?
  • If not, does the cluster structure suggest hidden factors which can be identified and included in the model?
  • Or does poor clustering of expected groups suggest experimental issues?

Why So Few Significant Genes?

Heatmaps display the transcriptomes directly as colored matrix columns. Clustering the columns can identify groups of samples with similar global gene expression, like PCA.

Boxplots of the matrix columns visualize the distributional properties of the per-sample counts.

… and of course the diagnostic tools of the DESeq2 package:

  • MA plot: graphs the mean normalized count agains the log2FoldChange
  • meanSdPlot: tries to transform the count distribution such that the standard deviation is ~identical for ~all of the genes
    • DESeq2’s differential gene expression analysis assumes that this is possible
    • if it is not possible, then the DGE results will likely be misleading!

Preparation for PCA

DESeq2’s vst() function implements this variance stabilizing transformation. 
It is meant to eliminate the increase in variance with count which is natural to count data.

We will use vst() to transform the input to PCA and heatmap functions.

A Barebones PCA Plotting Function

The DESeq2 package also provides a function plotPCA(), which executes a Principal Components Analysis and plots the result. It is an implementation of a generic function BiocGenerics::plotPCA. To see its code, type

# The triple colon operator shows non-exported code of a package
DESeq2:::plotPCA.DESeqTransform
function (object, intgroup = "condition", ntop = 500, returnData = FALSE, 
    pcsToUse = 1:2) 
{
    message(paste0("using ntop=", ntop, " top features by variance"))
    rv <- rowVars(assay(object))
    select <- order(rv, decreasing = TRUE)[seq_len(min(ntop, 
        length(rv)))]
    pca <- prcomp(t(assay(object)[select, ]))
    percentVar <- pca$sdev^2/sum(pca$sdev^2)
    if (!all(intgroup %in% names(colData(object)))) {
        stop("the argument 'intgroup' should specify columns of colData(dds)")
    }
    intgroup.df <- as.data.frame(colData(object)[, intgroup, 
        drop = FALSE])
    group <- if (length(intgroup) > 1) {
        factor(apply(intgroup.df, 1, paste, collapse = ":"))
    }
    else {
        colData(object)[[intgroup]]
    }
    pcs <- paste0("PC", pcsToUse)
    d <- data.frame(V1 = pca$x[, pcsToUse[1]], V2 = pca$x[, pcsToUse[2]], 
        group = group, intgroup.df, name = colnames(object))
    colnames(d)[1:2] <- pcs
    if (returnData) {
        attr(d, "percentVar") <- percentVar[pcsToUse]
        return(d)
    }
    ggplot(data = d, aes_string(x = pcs[1], y = pcs[2], color = "group")) + 
        geom_point(size = 3) + xlab(paste0(pcs[1], ": ", round(percentVar[pcsToUse[1]] * 
        100), "% variance")) + ylab(paste0(pcs[2], ": ", round(percentVar[pcsToUse[2]] * 
        100), "% variance")) + coord_fixed()
}

A Barebones PCA Plotting Function

plotPCA2 <-
    
function (object, ntop = 500, returnData = FALSE,
          pcsToUse=c(x=1,y=2),
          pointSize=3,
          hjust=-0.75,vjust=0.5,
          just_print_select=FALSE,
          print_labels=FALSE, 
          use_coord_fixed=FALSE,
          ...
          )  {

    ## Get the ntop most highly variable genes:  
    rv <- rowVars(assay(object))
    select <- order(rv, decreasing = TRUE)[seq_len(min(ntop, 
                                                       length(rv)))]
    if(just_print_select) {
        return(select)
    }
    
    ## Compute the PCA:
    pca <- prcomp(t(assay(object)[select, ]))
    percentVar <- pca$sdev^2/sum(pca$sdev^2)

    d <- data.frame(pca$x[, pcsToUse[1]], pca$x[, pcsToUse[2]], 
                    as.data.frame(colData(object)),
                    name = colnames(object))
    colnames(d)[1:2] <- paste("PC",pcsToUse,sep="")

    if (returnData) {
        attr(d, "percentVar") <- percentVar[pcsToUse]
        return(d)
    }
    
    ## Draw the scatterplot:
    p <- 
        ggplot(data = d,
               aes_string(x = paste("PC",pcsToUse["x"],sep=""),
                          y = paste("PC",pcsToUse["y"],sep="")
                          )
        ) + 
        geom_point(mapping = aes(
                      ...
                   ),
                   size = pointSize  ## set last, to override any "size"
                                     ## argument set inside aes()
                   
        ) +
        xlab(paste0("PC",pcsToUse["x"],": ", round(percentVar[pcsToUse["x"]] * 100), "% variance",sep="")) + 
        ylab(paste0("PC",pcsToUse["y"],": ", round(percentVar[pcsToUse["y"]] * 100), "% variance",sep=""))

    ## Add point labels if desired 
    if(print_labels) {
        p <- p +  geom_text(aes(label=rownames(d),hjust=hjust, vjust=vjust))
    }
    
    ## Set the ratio of the units on x and y axis to 1:
    if(use_coord_fixed) { 
        p <- p + coord_fixed() 
    }

    p
}

Subset the Dataset to One Tissue At a Time

The below function accepts a single metadata variable use_var and a vector use_levels of its levels. It returns a new dds object, which

  • contains only samples from the selected levels of the selected variable
  • has appropriate sizeFactors
  • no longer contains genes whose total count is less than min_count after sample restriction
  • no longer contains/needs use_var – all samples are now from use_var by definition

 

subset_dds <- 
  function(dds, use_var, use_levels, 
           design = NULL, min_count=10) {
    
    M <- counts(dds,normalize=FALSE)
    colData <- colData(dds)
    
    if(is.null(design)) { # use the design of the input object
      use_design <- design(dds) 
    } else { # set a custom design
      use_design = design
    }
    
    j <- colData[,use_var] %in% use_levels ## samples to keep
    i <- rowSums(M[,j]) >= min_count       ## rows to keep
    
    DESeqDataSetFromMatrix(countData = M[i,j],
                           colData = colData[j,] |> ## natively a DFrame ! 
                             as.data.frame() |>
                             dplyr::select(-!!use_var),
                           design= as.formula(use_design)
    ) |> DESeq()
  }
