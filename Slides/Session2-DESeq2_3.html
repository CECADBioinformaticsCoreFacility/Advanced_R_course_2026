Understanding Model Formulae

 

Model formulae like ~ 1 + genotype provide a high level language

  • for the experimenter to conceptually express a hypothesis about his or her data

  • for modeling software to know the structure of the tests to compute  

  • Independent of the actual mathematics of the tests !

An Additive Model of Gene Expression Including All Factors

We can use a model “~ age + sex + tissue + genotype” to describe the full dataset. At least in theory the model should partition the total variance in the data into the contributions of the experimental variables, such that we can study the genotype effect unconfounded.

library(DESeq2)

dds_additive <-
  # High level step 1: set up the object structure
    DESeqDataSetFromMatrix(countData = M,
                           colData = colData,
                           design= ~ age + sex + tissue + genotype 
                           ) |>
    DESeq()

These are the available test results:

Yet Another Alternative: Group Contrasts

There is another way to include all variables when testing for a genotype effect:

  • use the “group” factor (= the levels of all variables concatenated)
  • compare two level of "group" at a time,  
    differing only in genotype
  • this captures the effect of genotype in the context of the shared levels
  • notably all these contrasts are computed in a single model,  
    using information from the full dataset

Yet Another Alternative: Group Contrasts

The idea is embedded in a framework similar to Anova. Like Anova, it proceeds in two steps:

  • First we run DESeq() with a 0 + group model. This model tests whether the mean read count at a given “group” level is significantly different from zero. It is only meaningful as raw material for the later tests.
## See https://notchbio.app/blog/deseq2-multiple-conditions-contrasts-tutorial/

dds_group <-
  DESeqDataSetFromMatrix(countData = M,
                         colData = colData,
                         design= ~ 0 + group) |>
  DESeq()

Yet Another Alternative: Group Contrasts

For the second step we will need a table of the contrasts we want to test:

contrasts <-
  data.frame(group= "group",
             A  = colData |> 
                    dplyr::filter(genotype == "nmrhas2") |>
                    dplyr::pull(group),
             B=   colData |> 
                    dplyr::filter(genotype == "creer") |>
                    dplyr::pull(group)
  ) |> dplyr::distinct(.keep_all = TRUE) # there is initially one copy per replicate!

Yet Another Alternative: Group Contrasts

  • Then in the second "Anova" step, we call results() on the group means model with a contrast argument. This evaluates for every pair of “group” levels in the contrast table, whether their mean counts are significantly different.
# a matrix allows to directly extract rows as vectors
# (unlike a data.frame):
m <- as.matrix(contrasts)

res_contrasts <- list()
for(i in 1:nrow(m)) {

    res_contrasts[[i]] <- results(dds_group,
                                  contrast=m[i,]
                          ) 
}
# the second name in each contrast pair without the trailing ".creer"
# is the background -- use as name:
names(res_contrasts)  <- sub("\\.creer$","",contrasts[,"B"])
saveRDS(res_contrasts, file = "res_contrasts.rds")
